می‌شود کد را در هر ادیتوری نوشت، اما ادیتور درست کاری می‌کند که خیلی از خطاها را قبل از اجرای برنامه ببینید. این تفاوت بین «اجرا کردم و خطا داد» و «قبل از اجرا فهمیدم» است.

در این دوره از **VS Code** استفاده می‌کنیم.

## نصب

از [code.visualstudio.com](https://code.visualstudio.com) دانلود و نصب کنید.

بعد از نصب، پوشه پروژه‌ای که در درس قبل ساختید را باز کنید: از منوی `File` گزینه `Open Folder` را بزنید و پوشه `my-first-project` را انتخاب کنید.

<Callout type="warn">
همیشه **پوشه** پروژه را باز کنید، نه یک فایل تنها. VS Code فقط وقتی پوشه باز باشد می‌تواند `package.json` را بخواند و کتابخانه‌های نصب‌شده را بشناسد.
</Callout>

## دو extension که لازم دارید

نوار کناری، آیکون Extensions را بزنید و این دو را نصب کنید:

- **ESLint** — کد را می‌خواند و اشتباهات رایج را زیر خط قرمز می‌کشد، مثل متغیری که تعریف شده اما استفاده نشده.
- **Prettier** — شکل ظاهری کد را مرتب می‌کند: فاصله‌ها، نقل‌قول‌ها، سر خط رفتن‌ها.

این دو کار متفاوتی می‌کنند. ESLint می‌گوید کد شما اشکال دارد، Prettier می‌گوید کد شما نامرتب است.

## مرتب کردن خودکار هنگام ذخیره

کلید `Ctrl+Shift+P` را بزنید (در macOS: `Cmd+Shift+P`)، عبارت `Open User Settings (JSON)` را تایپ کنید و اینتر بزنید. فایلی باز می‌شود. این دو خط را داخل آکولاد اضافه کنید:

```json
{
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.formatOnSave": true
}
```

ذخیره کنید. از این به بعد هر بار که فایلی را ذخیره می‌کنید، خودش مرتب می‌شود.

این تنظیم کوچک ارزش زیادی دارد: دیگر وقتی برای بحث درباره شکل کد صرف نمی‌کنید، و کدی که در PR می‌فرستید با بقیه یکدست است.

## terminal داخل ادیتور

لازم نیست بین ادیتور و terminal جابه‌جا شوید. با کلید ``Ctrl+` `` یک terminal پایین صفحه باز می‌شود که از قبل داخل پوشه پروژه است.

در بقیه دوره، هر جا گفتیم «این دستور را اجرا کنید»، منظور همین terminal است.

## تمرین

فایلی به اسم `messy.js` بسازید، این کد نامرتب را داخلش بگذارید و ذخیره کنید. ببینید چه اتفاقی می‌افتد.

```js
const   name="Ali"
    console.log( "hello" ,name )
```

<Solution>

بعد از ذخیره، Prettier کد را به این شکل در می‌آورد:

```js
const name = 'Ali';
console.log('hello', name);
```

فاصله‌های اضافه حذف شدند، تورفتگی درست شد و نقطه‌ویرگول اضافه شد. خود کد هیچ تغییری نکرد، فقط ظاهرش مرتب شد.

اگر هیچ اتفاقی نیفتاد، یعنی Prettier به عنوان formatter انتخاب نشده. تنظیمات JSON را دوباره بررسی کنید.

</Solution>

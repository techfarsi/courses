## یک فایل بسازید

در پوشه پروژه، فایلی به اسم `hello.js` بسازید و این را بنویسید:

```js
console.log('سلام، دنیا');
```

ذخیره کنید. بعد در terminal:

```bash
node hello.js
```

خروجی:

```
سلام، دنیا
```

همین. `console.log` چیزی را که به آن می‌دهید در terminal چاپ می‌کند، و `node` فایل را از خط اول تا آخر اجرا می‌کند.

## متغیر و مقدار

برنامه‌ای که فقط یک جمله ثابت چاپ کند کاربردی ندارد. فایل را به این شکل تغییر دهید:

```js
const name = 'علی';
const year = 1404;

console.log('سلام', name);
console.log('امسال سال', year, 'است');
```

دو نکته:

- `const` یعنی مقداری که بعدا عوض نمی‌شود. تا وقتی دلیلی برای تغییر ندارید، همیشه `const` بنویسید.
- `'علی'` یک **string** است، متن داخل نقل‌قول. اما `1404` یک **number** است و نقل‌قول ندارد. این تفاوت مهم است و در درس‌های بعد به آن برمی‌گردیم.

## ترکیب متن

اگر بخواهید متن و متغیر را در یک جمله ترکیب کنید، از backtick استفاده کنید، همان کلید بالای Tab:

```js
const name = 'علی';

console.log(`سلام ${name}، خوش آمدید`);
```

خروجی:

```
سلام علی، خوش آمدید
```

به این template literal می‌گویند. هر چیزی داخل `${...}` بگذارید، محاسبه می‌شود و نتیجه‌اش داخل متن می‌نشیند:

```js
console.log(`۲ به علاوه ۳ می‌شود ${2 + 3}`);
```

## گرفتن ورودی

برنامه وقتی جالب می‌شود که ورودی بگیرد. Node.js آنچه بعد از اسم فایل تایپ می‌کنید را در `process.argv` می‌گذارد:

```js
const name = process.argv[2];

console.log(`سلام ${name}`);
```

حالا اجرا کنید:

```bash
node hello.js مریم
```

خروجی:

```
سلام مریم
```

چرا `[2]`؟ چون دو مورد اول همیشه مسیر Node.js و مسیر فایل شماست. ورودی‌های خود شما از شماره ۲ شروع می‌شوند.

<Callout type="info">
اگر بدون ورودی اجرا کنید، خروجی می‌شود `سلام undefined`. مقدار `undefined` یعنی «چیزی اینجا نیست». در درس‌های بعد یاد می‌گیرید چطور این حالت را مدیریت کنید.
</Callout>

## تمرین

برنامه‌ای بنویسید که دو عدد از خط فرمان بگیرد و حاصل جمعشان را چاپ کند:

```bash
node sum.js 4 7
```

خروجی باید این باشد:

```
4 + 7 = 11
```

<Solution>

```js
const a = Number(process.argv[2]);
const b = Number(process.argv[3]);

console.log(`${a} + ${b} = ${a + b}`);
```

نکته اصلی `Number()` است. هر چیزی که از خط فرمان می‌آید string است، حتی وقتی عدد به نظر می‌رسد. اگر `Number()` را بردارید، `'4' + '7'` می‌شود `'47'`، چون علامت `+` روی دو string به معنی چسباندن آنهاست، نه جمع کردن.

این یکی از رایج‌ترین اشتباهات شروع کار با JavaScript است.

</Solution>

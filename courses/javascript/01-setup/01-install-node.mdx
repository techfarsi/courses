کد JavaScript سال‌ها فقط داخل مرورگر اجرا می‌شد. Node.js همان موتور اجرای JavaScript را روی سیستم شما می‌آورد، بیرون از مرورگر. با آن می‌توانید فایل بسازید، به اینترنت وصل شوید، server بنویسید و ابزار خط فرمان بسازید.

در این دوره همه چیز با Node.js اجرا می‌شود، پس اولین قدم نصب آن است.

## نصب

به [nodejs.org](https://nodejs.org) بروید و نسخه **LTS** را دانلود و نصب کنید.

LTS یعنی Long Term Support، نسخه‌ای که پایدار است و مدت طولانی پشتیبانی می‌شود. نسخه Current جدیدتر است اما برای یادگیری به آن نیازی ندارید.

نصب را که تمام کردید، terminal را باز کنید:

- در macOS: برنامه Terminal
- در Windows: برنامه Windows Terminal یا PowerShell
- در Linux: terminal توزیع خودتان

## بررسی نصب

این دستور را بزنید:

```bash
node -v
```

باید چیزی شبیه این ببینید:

```
v22.11.0
```

عدد دقیق مهم نیست، فقط باید ۲۲ یا بالاتر باشد. اگر به جای آن پیام `command not found` گرفتید، یعنی نصب کامل نشده. terminal را ببندید و دوباره باز کنید، چون terminal تغییرات نصب را تا وقتی دوباره باز نشود نمی‌بیند.

## فعال کردن pnpm

برای نصب کتابخانه‌ها به یک package manager نیاز دارید. همراه Node.js ابزاری به اسم npm نصب می‌شود، اما در این دوره از **pnpm** استفاده می‌کنیم، که سریع‌تر است و فضای دیسک کمتری می‌گیرد.

pnpm از قبل داخل Node.js وجود دارد و فقط باید فعال شود:

```bash
corepack enable pnpm
```

حالا بررسی کنید:

```bash
pnpm -v
```

اگر عددی مثل `9.15.0` دیدید، آماده‌اید.

<Callout type="info">
از این به بعد در کل دوره فقط `pnpm` می‌بینید. هر جا در اینترنت دستوری با `npm install` دیدید، معادل آن `pnpm add` است.
</Callout>

## تمرین

یک پوشه خالی بسازید، وارد آن شوید، یک پروژه جدید بسازید و کتابخانه `chalk` را نصب کنید. بعد بررسی کنید که پوشه `node_modules` ساخته شده باشد.

<Solution>

```bash
mkdir my-first-project
cd my-first-project
pnpm init
pnpm add chalk
ls
```

در خروجی `ls` باید `node_modules`، `package.json` و `pnpm-lock.yaml` را ببینید.

`pnpm init` فایل `package.json` را می‌سازد، که شناسنامه پروژه شماست. `pnpm add chalk` کتابخانه را دانلود می‌کند، داخل `node_modules` می‌گذارد و اسمش را در `package.json` ثبت می‌کند.

</Solution>

ادیتور درست کاری می‌کند که خیلی از خطاها را قبل از اجرای برنامه ببینید. این تفاوت بین «اجرا کردم و خطا داد» و «قبل از اجرا فهمیدم» است.

در این دوره از **VS Code** استفاده می‌کنیم.

## نصب

از [code.visualstudio.com](https://code.visualstudio.com) دانلود و نصب کنید. بعد از منوی `File` گزینه `Open Folder` را بزنید و پوشه پروژه‌ای که در درس قبل ساختید را باز کنید.

<Callout type="warn">
همیشه **پوشه** پروژه را باز کنید، نه یک فایل تنها. VS Code فقط وقتی پوشه باز باشد می‌تواند virtual environment پروژه را پیدا کند و کتابخانه‌های نصب‌شده را بشناسد.
</Callout>

## دو extension که لازم دارید

آیکون Extensions را در نوار کناری بزنید و این دو را نصب کنید:

- **Python** (از Microsoft): اجرای کد، تشخیص خطا و راهنمایی هنگام تایپ.
- **Ruff**: کد را می‌خواند و هم اشتباهات رایج را می‌گیرد و هم ظاهرش را مرتب می‌کند.

Ruff جای چند ابزار قدیمی‌تر را یک‌جا گرفته و بسیار سریع است. به همین دلیل در این دوره فقط از همین یکی استفاده می‌کنیم.

## انتخاب interpreter

مهم‌ترین تنظیم این درس همین است. کلید `Ctrl+Shift+P` را بزنید (در macOS: `Cmd+Shift+P`)، عبارت `Python: Select Interpreter` را تایپ کنید و گزینه‌ای را انتخاب کنید که داخل پرانتز `.venv` دارد.

اگر این کار را نکنید، ادیتور از Python کل سیستم استفاده می‌کند، نه از محیط پروژه. نتیجه‌اش خطای عجیبی است که تازه‌کارها را گیج می‌کند: کد با `uv run` درست اجرا می‌شود، اما ادیتور زیر `import rich` خط قرمز می‌کشد و می‌گوید این کتابخانه پیدا نشد.

## مرتب کردن خودکار هنگام ذخیره

دوباره `Ctrl+Shift+P`، این بار `Open User Settings (JSON)`. این چند خط را داخل آکولاد اضافه کنید:

```json
{
  "[python]": {
    "editor.defaultFormatter": "charliermarsh.ruff",
    "editor.formatOnSave": true
  }
}
```

ذخیره کنید. از این به بعد هر فایل Python که ذخیره کنید خودش مرتب می‌شود: تورفتگی‌ها درست، فاصله‌های اضافه حذف و نقل‌قول‌ها یکدست.

در Python تورفتگی فقط زیبایی نیست، بخشی از معنی کد است. مرتب‌سازی خودکار یعنی یک دسته کامل از خطاها هیچ‌وقت اتفاق نمی‌افتند.

## terminal داخل ادیتور

با کلید ``Ctrl+` `` یک terminal پایین صفحه باز می‌شود که از قبل داخل پوشه پروژه است. در بقیه دوره هر جا گفتیم «این دستور را اجرا کنید»، منظور همین terminal است.

## تمرین

فایلی به اسم `messy.py` بسازید، این کد نامرتب را داخلش بگذارید و ذخیره کنید.

```py
name   =  "Ali"
print( "hello" ,   name )
```

<Solution>

بعد از ذخیره، Ruff کد را به این شکل در می‌آورد:

```py
name = "Ali"
print("hello", name)
```

فاصله‌های اضافه حذف شدند و نقل‌قول‌ها یکدست شدند. خود کد تغییری نکرد، فقط ظاهرش مرتب شد.

اگر هیچ اتفاقی نیفتاد، یعنی Ruff به عنوان formatter انتخاب نشده. بخش `[python]` در تنظیمات JSON را دوباره بررسی کنید.

</Solution>

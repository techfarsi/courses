Python زبانی است که برای خواندن آسان طراحی شده. همان کاری که در زبان‌های دیگر ده خط می‌برد، اینجا اغلب در سه خط نوشته می‌شود. به همین دلیل در تحلیل داده، هوش مصنوعی، اتوماسیون و ساخت server زیاد استفاده می‌شود.

## نصب

به [python.org/downloads](https://www.python.org/downloads/) بروید و آخرین نسخه پایدار را نصب کنید.

<Callout type="warn">
در Windows، هنگام نصب حتما تیک **Add Python to PATH** را بزنید. این تیک در صفحه اول نصب است و اگر از قلم بیفتد، terminal اصلا Python را پیدا نمی‌کند و باید دوباره نصب کنید.
</Callout>

در macOS و Linux معمولا نسخه‌ای از Python از قبل روی سیستم هست، اما قدیمی است و متعلق به خود سیستم‌عامل. نسخه رسمی را جداگانه نصب کنید و به آن کار نداشته باشید.

## بررسی نصب

terminal را باز کنید و بزنید:

```bash
python3 --version
```

باید چیزی شبیه این ببینید:

```
Python 3.13.1
```

عدد دقیق مهم نیست، فقط باید ۳.۱۲ یا بالاتر باشد.

در Windows اگر `python3` کار نکرد، `python --version` را امتحان کنید. اگر هیچ‌کدام جواب نداد، terminal را ببندید و دوباره باز کنید، چون terminal تغییرات نصب را تا وقتی دوباره باز نشود نمی‌بیند.

## نصب uv

برای ساختن پروژه و نصب کتابخانه‌ها از **uv** استفاده می‌کنیم، ابزاری که هم پروژه می‌سازد، هم کتابخانه نصب می‌کند و هم نسخه Python را مدیریت می‌کند.

در macOS و Linux:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

در Windows، داخل PowerShell:

```powershell
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```

terminal را ببندید و دوباره باز کنید، بعد بررسی کنید:

```bash
uv --version
```

<Callout type="info">
هر جا در اینترنت دستوری با `pip install` دیدید، معادل آن در این دوره `uv add` است.
</Callout>

## چرا محیط جدا

اگر کتابخانه‌ها را مستقیم روی خود سیستم نصب کنید، دو پروژه که به نسخه‌های متفاوتی از یک کتابخانه نیاز دارند به هم می‌خورند و یکی از کار می‌افتد.

راه‌حل این است که هر پروژه کتابخانه‌های خودش را در پوشه خودش داشته باشد. به این محیط جدا **virtual environment** می‌گویند. خبر خوب اینکه uv خودش این کار را انجام می‌دهد و شما لازم نیست کاری بکنید.

## تمرین

یک پروژه جدید به اسم `my-first-project` بسازید و کتابخانه `rich` را در آن نصب کنید.

<Solution>

```bash
uv init my-first-project
cd my-first-project
uv add rich
ls -a
```

در خروجی باید `pyproject.toml`، `uv.lock` و پوشه `.venv` را ببینید.

`uv init` اسکلت پروژه را می‌سازد و `pyproject.toml` شناسنامه آن است. `uv add rich` کتابخانه را دانلود می‌کند، داخل `.venv` می‌گذارد و اسمش را در `pyproject.toml` ثبت می‌کند. پوشه `.venv` همان virtual environment است که uv خودکار ساخت.

</Solution>

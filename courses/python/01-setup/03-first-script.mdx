## یک فایل بسازید

در پوشه پروژه، فایلی به اسم `hello.py` بسازید و این را بنویسید:

```py
print("سلام، دنیا")
```

ذخیره کنید، بعد در terminal:

```bash
uv run hello.py
```

خروجی:

```
سلام، دنیا
```

`print` چیزی را که به آن می‌دهید در terminal چاپ می‌کند.

<Callout type="info">
چرا `uv run` و نه `python hello.py`؟ چون `uv run` برنامه را داخل محیط پروژه اجرا می‌کند، جایی که کتابخانه‌های نصب‌شده شما هستند. تا آخر دوره همیشه با `uv run` اجرا می‌کنیم.
</Callout>

## متغیر و مقدار

فایل را به این شکل تغییر دهید:

```py
name = "علی"
year = 1404

print("سلام", name)
print("امسال سال", year, "است")
```

بر خلاف بعضی زبان‌ها، لازم نیست قبل از اسم متغیر کلمه‌ای مثل `const` بنویسید. اسم را می‌نویسید، علامت مساوی، و مقدار.

اما تفاوت `"علی"` و `1404` مهم است: اولی یک **string** است، متن داخل نقل‌قول، و دومی یک **int**، یعنی عدد صحیح بدون نقل‌قول.

## ترکیب متن

برای ترکیب متن و متغیر در یک جمله، قبل از نقل‌قول حرف `f` بگذارید:

```py
name = "علی"

print(f"سلام {name}، خوش آمدید")
```

خروجی:

```
سلام علی، خوش آمدید
```

به این **f-string** می‌گویند. هر چیزی داخل `{...}` بگذارید محاسبه می‌شود و نتیجه‌اش داخل متن می‌نشیند:

```py
print(f"۲ به علاوه ۳ می‌شود {2 + 3}")
```

اگر `f` را فراموش کنید، Python متن را عینا چاپ می‌کند، با همان آکولادها. این اولین چیزی است که وقتی خروجی عجیب دیدید باید بررسی کنید.

## گرفتن ورودی

برنامه وقتی جالب می‌شود که ورودی بگیرد. آنچه بعد از اسم فایل تایپ می‌کنید در `sys.argv` قرار می‌گیرد:

```py
import sys

name = sys.argv[1]

print(f"سلام {name}")
```

اجرا کنید:

```bash
uv run hello.py مریم
```

خروجی:

```
سلام مریم
```

خط `import sys` یعنی «به ابزارهای مربوط به سیستم دسترسی می‌خواهم». خانه شماره صفر در `sys.argv` همیشه اسم خود فایل است، پس ورودی‌های شما از شماره ۱ شروع می‌شوند.

## تمرین

برنامه‌ای بنویسید که دو عدد از خط فرمان بگیرد و حاصل جمعشان را چاپ کند:

```bash
uv run sum.py 4 7
```

خروجی باید این باشد:

```
4 + 7 = 11
```

<Solution>

```py
import sys

a = int(sys.argv[1])
b = int(sys.argv[2])

print(f"{a} + {b} = {a + b}")
```

نکته اصلی `int()` است. هر چیزی که از خط فرمان می‌آید string است، حتی وقتی عدد به نظر می‌رسد. اگر `int()` را بردارید، `"4" + "7"` می‌شود `"47"`، چون علامت `+` روی دو string یعنی چسباندن آنها به هم، نه جمع کردن.

</Solution>
